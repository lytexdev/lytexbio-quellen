## Quellen finden

Alle Quelldateien liegen unter [`videos/`](videos/). Für jedes Video gibt es eine eigene Markdown-Datei. Darin findest du die zugehörigen Originalquellen, eine kurze Einordnung und — soweit sinnvoll — eine Bewertung der Evidenz.

## Evidenz verstehen

- **Hoch:** belastbare, konsistente Evidenz, etwa aus mehreren hochwertigen randomisierten Studien oder systematischen Reviews.
- **Moderat:** aussagekräftige, aber begrenzte oder teils uneinheitliche Humanstudien.
- **Niedrig:** kleine, unkontrollierte oder methodisch eingeschränkte Humanstudien.
- **Vorläufig/präklinisch:** Tier-, Zell- oder mechanistische Forschung; keine gesicherte klinische Wirksamkeit beim Menschen.

Die Einstufung ist eine vereinfachte redaktionelle Orientierung und keine formale GRADE-Bewertung. Sie bezieht sich immer auf eine **konkrete Aussage**, nicht pauschal auf einen Wirkstoff.
